# SEC2021 — مقدمة في الحوسبة والبرمجة الحاسوبية

موقع تعليمي تفاعلي ثنائي اللغة (عربي/إنجليزي) لمقرر **SEC2021** في برنامج بكالوريوس المعلوماتية الصحية، جامعة أم القرى.

- موقع ثابت بالكامل: لا build step، ولا إطار عمل، ولا مكتبة خارجية.
- يعمل بفتح `index.html` مباشرة من القرص، وعلى GitHub Pages بلا إعداد إضافي.
- إعداد وإشراف علمي: د. أحمد الهندي · رخصة المحتوى: CC BY 4.0.

---

## 1. بنية الملفات

| الملف | ماذا يحتوي | متى تعدّله |
|---|---|---|
| `index.html` | هيكل الصفحة: الهيدر، شريط التقدم، القائمة الجانبية، حاوية المحتوى | نادراً |
| `styles.css` | نظام التصميم كاملاً، الوضعان النهاري والليلي، تنسيق الطباعة، والخط السعودي مضمَّناً base64 في آخر الملف | عند تغيير الشكل |
| `content.js` | بيانات المقرر والموديولات والأقسام وأوراق المراجعة | عند إضافة محتوى |
| `quizzes.js` | أسئلة التقييم الذاتي وتفسيراتها | عند إضافة أسئلة |
| `app.js` | نصوص الواجهة، اللغة، الوضع، التوجيه، تتبّع التقدم، محرّك الأسئلة، تكبير الصور | عند تغيير السلوك |
| `images/` | مجلد الصور التوضيحية — 20 صورة `.webp` للموديولات 1-3 | عند إضافة صورة |

> **قاعدة ملزمة:** كل نص في الموقع كائن بالشكل `{ ar: "...", en: "..." }`. لا يُضاف نص بلغة واحدة.

## 2. النشر على GitHub Pages

1. أنشئ مستودعاً جديداً على GitHub (مثلاً `sec2021`).
2. ارفع الملفات الخمسة ومجلد `images/` وملف `README.md` في **جذر** المستودع، لا داخل مجلد فرعي:
   ```bash
   git init
   git add .
   git commit -m "SEC2021 course site"
   git branch -M main
   git remote add origin https://github.com/<اسم-الحساب>/sec2021.git
   git push -u origin main
   ```
3. في صفحة المستودع: **Settings ← Pages**.
4. في `Source` اختر **Deploy from a branch**، وفي `Branch` اختر `main` والمجلد `/ (root)`، ثم **Save**.
5. انتظر دقيقة، ثم افتح الرابط:
   `https://<اسم-الحساب>.github.io/sec2021/`

**تحديث الموقع لاحقاً:** أي `git push` إلى `main` ينشر التغيير تلقائياً خلال دقيقة.

**بديل بلا سطر أوامر:** من واجهة GitHub اضغط `Add file ← Upload files`، واسحب الملفات، ثم `Commit changes`.

## 3. إضافة موديول جديد

في `content.js` أضف كائناً إلى مصفوفة `MODULES` بالقالب التالي:

```js
{
  id: "m4", n: 4, hours: 8, status: "ready", clos: ["1.2", "2.2"],
  title:   { ar: "عنوان الموديول", en: "Module title" },
  summary: { ar: "سطر أو سطران", en: "One or two lines" },
  recall:  { ar: "<p>صندوق التذكير السريع</p>", en: "<p>Quick recall box</p>" },
  sections: [
    {
      id: "s1",
      title: { ar: "عنوان القسم", en: "Section title" },
      html:  { ar: "<p>محتوى القسم بصيغة HTML</p>", en: "<p>Section content as HTML</p>" }
    }
  ],
  cheat: [
    { t: { ar: "مصطلح", en: "Term" }, d: { ar: "تعريف مختصر", en: "Short definition" } }
  ]
}
```

- `status: "ready"` يجعل الموديول قابلاً للفتح، و`"pending"` يعرضه في الخريطة معطّلاً بوسم «قيد الإعداد».
- `clos` أكواد مخرجات التعلم كما في `COURSE.clos`، وتظهر تلقائياً في جدول التغطية بالصفحة الرئيسة.
- ترتيب الموديول في القائمة يتبع ترتيبه في المصفوفة، و`n` هو رقمه المعروض.

### أصناف HTML الجاهزة داخل `html`

```html
<div class="box define"><span class="label">تعريف</span><p>...</p></div>
<div class="box scenario"><span class="label">من واقع العمل</span><p>...</p></div>
<div class="box recall"><span class="label">انتبه</span><p>...</p></div>
<div class="box warn"><span class="label">تنبيه</span><p>...</p></div>

<ol class="steps"><li>خطوة محلولة</li></ol>
<ul class="timeline"><li><span class="yr">1995</span>حدث</li></ul>
<div class="table-wrap"><table><caption>...</caption>...</table></div>
<div class="code">كود بايثون — يبقى LTR تلقائياً</div>
<span class="term">Term</span>        <!-- مصطلح إنجليزي داخل نص عربي -->
<span class="num">16 GB</span>        <!-- رقم أو وحدة لا تُعكس -->
<span dir="ltr">Windows 11</span>     <!-- أي نص لاتيني داخل فقرة عربية -->
```

## 4. إضافة سؤال تقييم ذاتي

في `quizzes.js`، داخل مصفوفة الموديول (المفتاح = `id` الموديول):

```js
{
  q: { ar: "نص السؤال؟", en: "Question text?" },
  options: [
    { ar: "الخيار الأول", en: "First option" },
    { ar: "الخيار الثاني", en: "Second option" },
    { ar: "الخيار الثالث", en: "Third option" },
    { ar: "الخيار الرابع", en: "Fourth option" }
  ],
  correct: 2,                                  // موضع الإجابة الصحيحة، يبدأ من 0
  why: { ar: "تفسير الإجابة", en: "Explanation" }
}
```

> **مهم:** وزّع قيم `correct` بين 0 و1 و2 و3 ولا تكرّر الموضع نفسه في أسئلة متتالية، وإلا اكتشف الطالب النمط وفقد السؤال قيمته. للتحقق من التوزيع الحالي:
> ```bash
> node -e "eval(require('fs').readFileSync('quizzes.js','utf8')+'');\
> Object.keys(QUIZZES).forEach(k=>console.log(k, QUIZZES[k].map(q=>q.correct).join('')))"
> ```

## 5. تتبّع التقدم

يُحفظ في `localStorage` تحت المفتاح **`sec2021-progress-v1`** ويضم: اللغة المختارة، والوضع النهاري/الليلي، وسجل الأقسام المقروءة.

```json
{ "lang": "ar", "theme": "light", "read": { "m1:s1": true } }
```

زر **تصفير التقدم** أسفل القائمة الجانبية يمسح سجل القراءة وحده. وإذا غيّرت بنية البيانات مستقبلاً، ارفع رقم الإصدار في المفتاح إلى `-v2` حتى لا تتعارض مع سجلات الطلاب القديمة.

## 6. اللغة والاتجاه

- زر اللغة في الهيدر يبدّل بين العربية والإنجليزية ويحفظ الاختيار.
- عند العربية تُضبط `dir="rtl"` و`lang="ar"` على عنصر `<html>`، والتنسيق كله بخصائص CSS المنطقية (`margin-inline-start` وأخواتها) فينعكس الاتجاه تلقائياً بلا أي حيلة نصية.
- أي نص عربي داخل كتلة كود أو صيغة LTR يُلفّ بـ `<bdi>` حتى لا تنتقل علامات الترقيم إلى الطرف الخاطئ، وشبه الكود العربي يستخدم `class="code rtl"`.
- الأرقام غربية (0-9) في اللغتين. **لا تستخدم** `toLocaleString('ar')` ولا `Intl.NumberFormat('ar-SA')` فهي تُخرج أرقاماً شرقية؛ استخدم `'ar-u-nu-latn'` أو `{ numberingSystem: 'latn' }` إن احتجت تنسيقاً.
- الخط العربي: **الخط السعودي الرسمي** (وزارة الثقافة) — عائلة `Saudi` للعناوين و`Saudi Text` للنصوص، مضمَّنة في `styles.css` بصيغة woff2 مختصرة على النطاقات المستخدمة، فيعمل الموقع بلا إنترنت. الإنجليزية تستخدم خط النظام اللاتيني.

## 8. إضافة صورة توضيحية

الصور تعيش في مجلد `images/` بجوار الملفات الخمسة، وتُشير إليها بمسار نسبي فتعمل محلياً وعلى GitHub Pages بلا تغيير.

### التسمية
`sec2021-m<رقم الموديول>-<رقم تسلسلي داخل الموديول>-<وصف-بالإنجليزية>.webp`
مثال: `images/sec2021-m3-06-users-security-permissions.webp`

ورقم الشكل في التعليق يطابق اسم الملف: الصورة `sec2021-m3-06-...` تُعنون «شكل 3.6»، فيسهل على أي شخص لاحقاً أن يصل من التعليق إلى الملف مباشرة.

الأسماء بحروف لاتينية صغيرة وشرطات فقط — لا مسافات ولا حروف عربية، لأن بعض الخوادم تكسر الروابط التي تحوي محارف غير لاتينية.

### الصيغة والحجم
حوّل الصورة إلى **WebP** قبل الرفع؛ صورة ChatGPT بمقاس 1536×1024 تنزل من نحو 1.8 ميجابايت إلى نحو 300 كيلوبايت بلا فقد محسوس في حدة النص:

```bash
python3 -c "from PIL import Image; Image.open('src.png').save('images/m3-06-users-permissions.webp','WEBP',quality=92,method=6)"
```

### الكود داخل `content.js`

توضع كتلة الشكل داخل `html` في اللغتين — الصورة نفسها في الاثنتين، والنص البديل والتعليق بلغة كل نسخة:

```html
<figure class="fig">
  <img src="images/m3-06-users-permissions.webp"
       alt="وصف دقيق لما تعرضه الصورة، لقارئ الشاشة ولمن لا تُحمّل عنده الصورة"
       loading="lazy" width="1536" height="1024">
  <figcaption><span class="n">شكل 3.6</span> تعليق قصير يشرح ما الذي تنظر إليه.</figcaption>
</figure>
```

- `width` و`height` الحقيقيان يمنعان قفزة التخطيط أثناء التحميل.
- `loading="lazy"` يؤجل تحميل الصور البعيدة عن الشاشة.
- النقر على الصورة يفتحها مكبّرة في نافذة تُغلق بمفتاح Escape أو بالنقر خارجها؛ لا يلزمك إعداد شيء، فالسلوك يُربط تلقائياً بأي صورة داخل `figure.fig`.
- ترقيم الأشكال يدوي داخل `figcaption` بصيغة «شكل رقم الموديول.رقم القسم».

### التحقق بعد الإضافة
```bash
node -e "const s=require('fs').readFileSync('content.js','utf8');\
const used=[...new Set(s.match(/images\/[a-z0-9-]+\.webp/g))].map(x=>x.split('/')[1]);\
const have=require('fs').readdirSync('images');\
console.log('مفقودة:', used.filter(x=>!have.includes(x)));\
console.log('غير مستخدمة:', have.filter(x=>!used.includes(x)));"
```

### إن كانت الصورة تحمل نصاً
اكتب في `alt` ما تقوله الصورة فعلاً لا اسمها فقط، لأن الصورة وحدها لا تكفي لقارئ الشاشة ولا للطالب الذي يطبع المادة بالأبيض والأسود.
