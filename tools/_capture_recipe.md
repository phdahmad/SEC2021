# وصفة الالتقاط بلا فقدان (PNG) — SEC2021

ثبت أن `computer_zoom` و`computer_screenshot` يُرجعان **JPEG دائماً** ولا خيار لصيغة أخرى،
وضغط JPEG هو ما أتلف حروف الأيقونات. والبديل المثبت:

## الوصفة

1. **الصلاحيات** (مرة واحدة في الجلسة):
   - `computer_request_access` لـ Excel · Word · PowerPoint · «أداة القصاصة»
     (`Microsoft.ScreenSketch_8wekyb3d8bbwe!App`) · File Explorer، مع `systemKeyCombos: true`.
   - `device_request_folder_access` لـ `~/Pictures/Screenshots`.
2. **لكل حالة شريط**، نداء واحد:
   ```
   key  win+shift+s          ← يفتح طبقة القصّ
   wait 3
   left_click_drag (3,3) → (1453,816)    ← الشاشة كاملة
   wait 3
   key  escape               ← يغلق الطبقة (بدونها تظهر كل اللقطات سوداء)
   key  alt                  ← يُظهر مفاتيح الوصول
   wait 1
   type <حرف التبويب>
   wait 2
   ```
3. تُحفظ اللقطة تلقائياً في `~/Pictures/Screenshots` باسم «لقطة شاشة YYYY-MM-DD HHMMSS.png»
   بدقّة **3824×2144** بلا فقدان.
4. `device_bash: ls -t "$HOME/mnt/Screenshots"/*.png | head` لمعرفة الأحدث، ثم
   `device_stage_files` لسحبها (حتى 50 ملفاً في النداء الواحد).
   ملف أصغر من ~50 كيلوبايت = قصّة فاشلة، أعِد الحالة.
5. القصّ والتأطير والترقيم يجري هنا في الحاوية، كما في `_shots*.py`.

## مفاتيح تبويبات وورد (الواجهة العربية)

| التبويب | المفتاح |
|---|---|
| الشريط الرئيسي | ء |
| إدراج | ه |
| تصميم | ا |
| تخطيط | ط |
| مراجع | س |
| مراسلات | ظ |
| مراجعة | ة |
| عرض | ص |

> النقر على تبويبات الشريط **لا يسجَّل** في أوفيس عبر هذه الأدوات — استخدم `alt` + الحرف دائماً.

## ملاحظات مهمة

- اسم التبويب الأول في هذا الإصدار هو **«الشريط الرئيسي»** لا «الصفحة الرئيسية».
- التطبيقات غير المصرّح بها (Chrome · Edge · Telegram · إدارة المهام) **تسرق التركيز**
  كل بضع ثوانٍ فتُفشل النداء. يجب إغلاقها قبل جولة الالتقاط.
- بعد كل قصّة: `escape` ضروري، وإلا بقيت طبقة القصّ فوق الشاشة وظهر كل تكبير أسود.

## الحالات المطلوبة

- وورد: 25 حالة (8 تبويبات + نوافذ: بحث واستبدال · طباعة · جزء الحماية · تبويبا الجدول · شريط الحالة)
- إكسل: 13 حالة
- بوربوينت: 19 حالة

## خطوة لا تُنسى

بعد `alt` + الحرف، **انقر داخل المستند أو الخلية** قبل القصّ، وإلا ظهرت
مفاتيح الوصول (المربعات الصغيرة على كل زر) في اللقطة.

## ما التُقط حتى الآن (3824×2144، PNG)

وورد — ثمانية تبويبات: `word-home` · `word-insert` · `word-design` ·
`word-layout` · `word-references` · `word-mailings` · `word-review` · `word-view`

إكسل — سبعة تبويبات: `xl-home` · `xl-insert` · `xl-pagelayout` ·
`xl-formulas` · `xl-data` · `xl-review` · `xl-view`
(المصنّف فيه جدول عيادات تجريبي في A1:D5)
